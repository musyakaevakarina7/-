## Как пользоваться каждый день

1. **Утром** открыть [Часть 6](strategy/06-plan-30-dney.md) (первые 30 дней) или [календарь 7.4](strategy/07-kalendar.md) → карточка сегодняшнего дня.
2. **В воскресенье** 20 минут: заполнить карточки роликов на неделю ([5.1](strategy/05-proizvodstvo.md)).
3. **В понедельник** 30 минут: «Разбор полётов» ([5.4](strategy/05-proizvodstvo.md)).
4. **Если нет сил** — [7.6 «Если бы я был Сергеем, я бы делал только это»](strategy/07-kalendar.md).
